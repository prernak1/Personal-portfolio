I enjoy solving complex backend problems involving performance, scalability, and system reliability. Recent highlights include leading a REST API microservice for real-time financial datasets, and modernizing legacy Fixed Income pipelines (NTLM → OAuth, Kubernetes CronJobs) that cut failures by 95%.
