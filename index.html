Who I Am

Backend-focused Software Engineer with 3+ years of experience building scalable, distributed systems in production environments. Currently working as SDE II at S&P Global, where I design and optimize microservices, data pipelines, and cloud-based architectures handling enterprise-scale financial data.

I have hands-on experience in event-driven systems using Apache Kafka — designing topics, partitioning strategies, consumer groups, and exactly-once semantics for high-throughput data ingestion pipelines. My cloud work spans GCP (BigQuery, Cloud Storage, Dataflow), AWS (Secrets Manager, IAM), and Azure (Application Insights, DevOps) — with a strong focus on observability using Prometheus metrics, OpenSearch dashboards, and ELK Stack for log aggregation and alerting.

On the .NET side, I've worked extensively with ASP.NET Core, hosted services, background workers, and middleware pipelines. I've containerized Windows-based services using Docker, automated deployments through GitHub Actions CI/CD, and integrated secure credential management via OAuth 2.0 and AWS Secrets Manager — replacing legacy NTLM auth and hardcoded secrets across production systems.

I enjoy solving complex backend problems involving performance, scalability, and system reliability. Recent highlights include engineering a Credit Default Swap (CDS) data processing microservice combining scheduled SQL batch extraction with real-time Kafka streaming, and a .NET Framework 4.6.2 → .NET 9 migration that cut production incidents by 99%.
